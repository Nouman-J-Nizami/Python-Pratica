# Python Geometric Calculator

## Overview

This project demonstrates the development of interactive Python applications designed to calculate perimeter and area values for multiple geometric shapes.

The exercises focus on fundamental programming concepts including user input handling, conditional statements, loops, mathematical operations, and dynamic data structures.

Developed as part of the Cybersecurity Analyst training program using Python 3 in a Linux environment.

---

## Project Features

### Basic Version
- User-driven geometric shape selection
- Perimeter calculation for:
  - Square
  - Rectangle
  - Circle
- Input validation through conditional logic
- Mathematical formula implementation

### Advanced Version (Optional)
- Automatic calculation of both perimeter and area
- Single input reused across multiple calculations
- Dynamic menu management
- Figure removal after selection
- Iterative processing using loops and lists
